## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Project Library** | Organize Amadine vector projects with client and status tags |
| **Color Palettes** | Save and reference named color palettes per project or brand |
| **Style Guide** | Document illustration style rules and reference examples |
| **Device Sync Notes** | Track which projects are synced across Mac and iPad |
